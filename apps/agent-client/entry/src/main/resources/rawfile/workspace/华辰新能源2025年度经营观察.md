# 华辰新能源2025年度经营观察：收入增长延续，利润率与回款成为新焦点

> 本文为功能测试而编写，华辰新能源及文中业务、人物与数据均为虚构内容，不构成投资建议。

2026年3月18日，储能与动力电池厂商华辰新能源发布2025年度经营简报。公司全年实现营业收入128.4亿元，同比增长18.2%；归属于母公司股东的净利润9.6亿元，同比增长12.5%；扣除非经常性损益后的净利润8.7亿元，同比增长7.4%。收入继续保持两位数增长，但利润增速低于收入增速，全年综合毛利率由上年的23.1%下降至21.8%。管理层称，储能系统出货扩大是增长主因，而动力电池价格竞争、海外工厂爬坡费用以及产品结构变化压低了利润率。

分业务看，储能系统收入61.5亿元，同比增长29%，占总收入的47.9%，首次成为公司最大业务。全年储能系统出货量达到18.6GWh，同比增长34%，平均销售价格则下降约4%。国内大型独立储能项目贡献了主要增量，来自东南亚和中东的海外收入也有所增加。动力电池业务收入46.8亿元，同比增长8%，其中商用车电池销量增长较快，但乘用车客户主动降价，使该板块毛利率下降2.6个百分点。运维、能源管理软件及其他服务收入20.1亿元，同比增长18%，订阅类收入占服务板块的比例由上年的22%升至29%。

费用方面，公司研发投入8.9亿元，同比增长21%，主要用于高安全储能电芯、钠离子电池和能源管理平台。销售费用增长16%至4.2亿元，管理费用增长11%至3.8亿元。由于收入增长快于销售和管理费用，两项费用率合计略有下降；但研发投入增加、海外基地试生产损失以及第四季度计提的0.7亿元存货跌价准备，对营业利润形成压力。非经常性损益约0.9亿元，主要包括政府研发补助和处置闲置设备收益，这也解释了归母净利润与扣非净利润增速之间的差距。

季度走势显示，第四季度营业收入37.2亿元，同比增长15%，归母净利润1.9亿元，同比下降9%。第四季度综合毛利率降至19.4%，明显低于全年水平。公司表示，行业年末集中交付带来收入确认高峰，但部分国内储能项目采取竞争性报价，同时海外新厂尚未达到设计产能，单位制造成本偏高。管理层预计海外工厂在2026年下半年达到约70%的产能利用率，但这一目标仍取决于当地认证进度和客户订单转化。

现金流表现好于利润增速。全年经营活动产生的现金流量净额14.2亿元，同比增长35%，为归母净利润的1.48倍。公司称，预收部分大型储能项目货款和加强逾期账款催收带来了改善。不过，年末应收账款仍达到24.6亿元，同比增长32%，明显快于收入增速；其中账龄超过一年的应收款占比由8%升至11%。存货为19.3亿元，同比增长6%，增速相对温和。公司对两家回款较慢的工程客户计提了额外坏账准备，但未披露具体客户名称。

2025年资本开支为17.8亿元，主要投向海外电池工厂和国内储能系统集成基地。按经营现金流减资本开支的简化口径计算，自由现金流约为负3.6亿元，较上年的负7.1亿元有所改善，但仍未转正。截至年末，公司货币资金31.7亿元，有息负债42.5亿元，其中一年内到期债务13.4亿元。资产负债率由56.2%升至58.7%。公司已获得尚未使用的银行授信28亿元，并计划通过降低2026年扩产强度改善现金状况。

订单方面，截至2025年末，华辰新能源储能系统在手订单金额约72亿元，其中海外订单占31%。管理层给出的2026年收入指引为145亿元至155亿元，对应约13%至21%的增长；计划资本开支约12亿元，低于2025年。公司预计原材料价格总体稳定，储能出货仍将增长，但没有承诺毛利率回升幅度。若低价竞争持续、海外项目延期或主要客户回款恶化，收入增长未必能够同步转化为利润和自由现金流。

值得关注的是，公司前五大客户收入占比从37%上升至44%，最大客户占比达到14%。更高的客户集中度有助于获得规模订单，也可能削弱议价能力并放大单一项目延期的影响。此外，海外工厂建设比最初计划晚了约四个月，当地补贴仍有1.2亿元尚未到账。公司认为认证工作已进入最后阶段，但并未披露补贴回收的确定时间。

供应链方面，碳酸锂和磷酸铁锂价格在2025年整体处于相对低位，使电芯材料成本下降，但降价收益并未完全留在公司内部。部分客户合同设有原材料价格联动条款，材料降价会在下一季度传导至产品售价；新增储能项目的招标价格也持续下探。公司通过年度采购协议锁定约60%的关键材料需求，并引入第二供应商降低断供风险。与此同时，高安全储能电芯采用的新型隔膜和热管理部件仍依赖少数供应商，议价空间有限。如果关键材料价格突然反弹，而产品售价调整存在滞后，短期毛利率可能再次受到挤压。

产能利用率是判断盈利修复的重要变量。国内电芯基地平均利用率约82%，储能系统集成基地约76%，处于能够摊薄固定成本的水平；海外新厂全年平均利用率只有28%，第四季度升至46%。公司测算，当海外工厂利用率达到60%以上时，单位制造成本会明显下降，达到75%左右时可接近国内成熟工厂的成本水平。不过，这一测算建立在订单按期交付、良品率持续提升和本地供应链顺利导入的基础上。若认证再次延期，即使设备已经安装完成，折旧、人工和维护费用仍会继续发生，形成阶段性亏损。

研发项目的商业化节奏也值得观察。公司预计高安全储能电芯将在2026年第二季度开始批量交付，首批订单约2.4GWh；钠离子电池仍处于客户验证阶段，年内收入贡献可能有限。能源管理平台已经连接超过3.1万个终端设备，年度经常性收入约2.6亿元，续费率为87%。软件收入规模目前不大，却具有较高毛利率和较轻资本投入，如果订阅占比继续提升，可能缓解硬件价格竞争带来的压力。相反，如果研发项目长期停留在验证阶段，持续投入会先体现为费用，而无法及时转化为收入和现金流。

进一步拆解应收账款可以看到，工程类客户是风险集中区域。公司给予核心客户的正常账期多为90天至180天，但部分大型项目需要等并网验收后才支付尾款。2025年末尚未完成验收的合同资产为7.8亿元，同比增长38%。管理层表示大部分项目预计在2026年上半年完成验收，但如果电网接入、地方审批或总包方结算延迟，账面收入与现金回收之间的时间差还会扩大。投资者除了关注经营现金流总额，也需要比较应收账款、合同资产和信用减值损失的变化，判断现金流改善究竟来自持续回款，还是来自阶段性的预收款增加。

行业需求仍有结构性支撑。随着新能源发电占比提高，电网调峰、独立储能和工商业峰谷套利的需求继续增加，多地容量补偿和辅助服务规则也逐步明确。不过，需求增长并不意味着所有供应商都能获得同等回报。国内项目招标更关注全生命周期度电成本，客户不仅比较设备价格，还会评估循环寿命、系统效率、消防设计和长期运维能力。华辰新能源正在从单纯设备销售转向“设备加运维加能源管理”组合，但服务收入形成规模需要较长周期，短期内硬件仍决定大部分收入和利润。因此，行业景气度与公司盈利能力之间并非简单同步关系。

在手订单也需要区分数量和质量。72亿元订单中，约63%已经收到定金，21%处于等待客户融资或并网批复阶段，其余订单尚未满足全部生效条件。公司披露的订单金额按照合同名义价值统计，并不等同于未来一年可确认的收入。部分海外合同包含汇率、运费和原材料调整条款，最终收入可能随交付条件变化；部分国内项目则设置性能考核，如果系统效率和可用率未达到约定水平，尾款可能被扣减。分析订单时应重点观察定金比例、交付周期、取消条款和客户资金来源，而不能只依据订单总额判断增长确定性。

产品质量和质保负担是储能企业容易被忽略的长期风险。公司为储能系统提供五年至十年的有限质保，并按相关收入的1.6%计提预计负债，年末质保准备余额2.1亿元。2025年实际质保支出0.6亿元，暂时低于当期计提金额，但大部分产品仍处于寿命早期，长期故障率尚未经过完整周期验证。公司报告期内没有发生重大安全事故，不过完成了三批次热管理部件的预防性更换，费用约0.18亿元。若未来电芯衰减、温控系统或软件控制出现共性问题，维修成本和品牌影响可能在收入确认多年后才显现。

营运资金变化显示，公司增长仍然需要占用现金。剔除预收款影响后，应收账款周转天数由上年的58天上升至65天，存货周转天数从71天下降至64天，应付账款周转天数则由83天延长至91天。库存管理改善释放了一部分现金，但更长的应付周期也意味着公司在利用供应商信用支持扩张。如果供应商要求缩短账期，或者公司为了争取客户继续放宽回款条件，现金转换周期可能重新拉长。经营现金流14.2亿元值得肯定，但其可持续性仍要结合预收款、票据结算和应付账款的变化共同判断。

债务结构方面，有息负债中约55%为固定利率借款，其余主要为浮动利率贷款和供应链融资。2025年利息费用1.7亿元，同比增长24%，利息保障倍数由上年的7.1倍下降至6.3倍，目前仍处于可控水平。公司计划用经营回款偿还部分短期贷款，并将海外项目贷款期限延长至五年以上。如果基准利率上升一个百分点，按年末浮动利率债务粗略估算，年度税前利润可能减少约0.2亿元；如果自由现金流持续为负，公司还可能需要新增借款。因而降低资本开支不仅影响扩产速度，也直接关系到资产负债表的安全边际。

资本配置与治理将影响增长成果能否转化为股东价值。董事会在年度简报中把自由现金流转正列为2026年的优先目标，并提出新增项目必须满足内部收益率和回收期要求。公司暂未公布大规模分红或回购计划，拟将资金优先用于偿还到期债务、完成海外工厂建设以及支持核心研发项目。管理层薪酬考核中，收入增长权重由40%降至30%，自由现金流、应收账款周转和安全质量指标的合计权重提高到35%。这种调整方向较为积极，但仍需观察实际执行结果，以及公司是否会在行业需求旺盛时再次启动超出现金承受能力的扩产。

按照公司指引，可以构造三种经营情景。乐观情景下，储能出货延续25%以上增长，海外工厂利用率按期提升，综合毛利率回升至22%以上，经营现金流覆盖资本开支，自由现金流转正。基准情景下，收入达到指引中值，产品降价与成本下降大致抵消，毛利率维持在21%至22%，自由现金流接近盈亏平衡。谨慎情景下，行业报价继续下行、海外订单延期且应收账款周转恶化，即使收入仍增长，利润和现金流也可能承压。三种情景的差异说明，单看出货量和收入不足以判断经营质量，还需要同时跟踪价格、利用率、回款和资本投入。

总体而言，华辰新能源2025年的核心亮点是储能业务推动收入增长、经营现金流改善以及资本开支计划趋于收敛；主要压力则来自毛利率下降、应收账款增速偏高、自由现金流仍为负以及海外产能爬坡的不确定性。2026年能否实现更高质量增长，关键不只是收入是否达到指引，还要观察储能报价、第四季度偏低的毛利率能否修复、应收账款周转是否改善，以及海外工厂能否按计划提升利用率。
