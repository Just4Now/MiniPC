# Agent 执行与结果规则

- 工具调用和结果按 callId 关联；类型化状态不从正文关键词推断。
- 输入整批校验，权限、并行和缓存来自可信注册策略。
- 共享注册表串行化可能改变状态的调用，取消等待中的调用不执行。
- 当前证据与历史上下文分开；最终综合无工具权限且次数有上限。
- 综合失败保留真实结果；partial 答复不作为完整事实写入会话历史。
- 页面代次、模型 owner 和工具命名空间隔离取消及迟到输出。

详细定义见 [Agent 执行流程](../docs/agent-workflow.md) 和 [工具契约](../docs/agent-tool-contracts.md)，测试入口见 [测试](../docs/testing.md)。
